# 第一章 片段阅读

## 第一节 中心理解题

### 转折关系：转折之后是重点

- 典型标志词
  - 虽然……但是……；尽管……可是……；不过……；然而；却；其实/事实上/实际上
- 非典型标志词
  - 殊不知；截然不同；截然相反；全新的研究；一种误读；相对尔雅
- 粉笔提示
  - 错误选项特征
    - 转折前的内容
    - 围绕例子、原因、背景……的表述，围绕解释说明的表述
    - 无中生有
    - 与文意相悖
  - 略读句子特征
    - 例子、原因……

### 主题词

- 特征
  - 文段围绕其展开
  - 一般高频出现
  - 多为名字
  - 前有引入或后有解释说明
  - 判断方法：（1）中心句围绕的核心话题，一般前有引入或后有解释说明  
    （2）每句话都围绕的相同话题
- 理论要点
  - 正确选项中需要包含文段主题词
- 干扰选项
  - 范围扩大/缩小/偷换
- 错误选项特征
  - 非重点
    - 转折前的内容
    - 围绕解释说明的表述
  - 无中生有
  - 偷换概念：主题词（偷换/范围扩大或缩小）

### 因果关系：结论是重点

- 典型格式
  - 因为……所……由于……因此……
- 结论标志词
  - 所以、因此、因而、故而、于是、可见、看来
  - 导致、致使、使得、造成
